# SimuCanarias

Simulador del ejercicio único del Gobierno de Canarias 2026: C1 Administrativo (17 de octubre) y C2 Auxiliar Administrativo (31 de octubre). Usa exámenes oficiales publicados por la Dirección General de la Función Pública, corregidos con las reglas de las bases (BOC n.º 57/2026).

Herramienta independiente, no oficial y sin relación con el Gobierno de Canarias.
